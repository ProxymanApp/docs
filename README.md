# Overview

## 1. Proxyman

Proxyman is a fast HTTP debugging proxy for macOS, Windows, Linux, iOS and Android. Use it to view and change HTTP/HTTPS requests and responses from apps, browsers and devices, including iOS devices, iOS Simulators, Android devices and Android Emulators.

## 2. Features

* [x] ✅ Intercept HTTP/HTTPS (SSL) requests from your Mac, iOS Simulators, iOS devices, Android devices and Android Emulators 📱.
* [x] Built for Apple Silicon and macOS 26 Tahoe
* [x] ✅ Built on Apple SwiftNIO for high performance
* [x] 🦋 Modern and intuitive UI.
* [x] 🍸 Liquid Glass UI for macOS 26
* [x] ⭐️ Native app on macOS. ElectronJS-based app for Windows and Linux
* [x] 📱 Apps for iOS and Android to capture traffic directly on your phone
* [x] 👑 Debugging tools: Compose, Repeat, ...
* [x] 🛠 Advanced Tools: Map Local, Map Remote, Breakpoint, Allow List, Block List, External Proxying, No Caching, Clear Cache, Protobuf, Scripting (Rewrite), and Diff.
* [x] 👨‍💻 Customizable workspace.
* [x] 🖥 Supports macOS 14 Sonoma or later
