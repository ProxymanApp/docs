# Code Generator

## 1. What's it?

Code Generator turns your captured HTTP/HTTPS requests into ready-to-use code for many languages and tools.

Supported languages and formats:

* cURL
* HTTPie
* HAR
* Postman Collection 2
* Axios
* Dart
* Go
* Java + HTTPClient
* JavaScript + jQuery
* Kotlin + OkHttp
* Node + HTTP
* Node + Fetch
* PHP + Guzzle
* Python + Request
* Rust + reqwest
* Objective-C + NSURLSession
* Swift + Alamofire 5
* Swift + Moya
* Swift + URLSession

![Proxyman Code tab with Swift + Alamofire 5 code generated from a captured GET request](../.gitbook/assets/code-generator.png)

## 2. How to open the Code Generator Tab?

1. In the Request panel, click the "+" button
2. The Custom Previewer Tab window appears -> check the **Code Generator** checkbox

<figure><img src="../.gitbook/assets/CleanShot 2025-01-29 at 3 .44.21@2x.jpg" alt="Proxyman Custom Previewer Tab window with Code Generator checked and the Code tab showing Swift code"><figcaption><p>How to open the Code Generator tab</p></figcaption></figure>

* A new **Code** tab is added to the Request panel -> select any language to show the code

## 3. Missing your favorite library?

If you can't find your library, you can:

* Create a [ticket on GitHub](https://github.com/ProxymanApp/Proxyman/issues).
* Fork the [Code-Generator-Plugin repository](https://github.com/ProxymanApp/code-generator-plugin) and open a PR. We appreciate your contribution 🙇‍♂️
