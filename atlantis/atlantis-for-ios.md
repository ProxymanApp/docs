# Atlantis for iOS

## 1. What's it?

Atlantis is a lightweight iOS framework by Proxyman for intercepting HTTP/HTTPS and WS/WSS traffic from your iOS app. You don't need to set up a proxy or a certificate.

![Atlantis by Proxyman logo](../.gitbook/assets/cover.png)

* **GitHub**: [https://github.com/ProxymanApp/atlantis](https://github.com/ProxymanApp/atlantis)

## 2. Benefit?

* Automatically intercept all **HTTP/HTTPS** Traffic with ease.
* Automatically intercept **WebSocket** from iOS devices.
* Support iOS Physical Devices and Simulators
* **No need** to configure an HTTP Proxy, or install and trust any Certificate
* Review traffic logs in the [Proxyman](https://proxyman.com/) macOS app.
* Categorize the log by app and devices.

{% hint style="info" %}
**Atlantis** is only for **Network Inspectors**. If you want to use Debugging Tools like Map Local, Breakpoint, Map Remote, Scripting, Network Throttling, and Reverse Proxy, please use a normal Proxy.
{% endhint %}
