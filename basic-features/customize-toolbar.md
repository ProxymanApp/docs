# Customize Toolbar

## 1. What's it?

From Proxyman 2.32.0, you can customize your toolbar to fit your needs.

You can add these tool buttons to your toolbar:

* Proxy Overridden
* Block List
* Allow List
* Breakpoint
* Map Local
* Map Remote
* Reverse Proxy
* Network Throttling
* Scripting
* No Caching
* SSL Proxying
* External Proxy

Each tool button turns its tool on or off.

![Customize Toolbar sheet of an older Proxyman version with tool toggle buttons such as Breakpoint and Scripting](../.gitbook/assets/Screen\_Shot\_2021-08-28\_at\_17\_15\_16.png)

## 2. How to use it?

You can open the Customize Toolbar sheet from:

* Right-click the toolbar → **Customize Toolbar…**
* **Tools** menu → **Customize Toolbar…**

{% hint style="info" %}
Customize Toolbar works on every macOS version that Proxyman supports (macOS 14 Sonoma or later).
{% endhint %}
