# ElectronJS

## 1. Problem

Many ElectronJS apps ignore the system HTTP proxy, so Proxyman can't capture HTTP/HTTPS traffic from them :x:

## 2. Solution

From Proxyman macOS 6.7.0 or later:

* Capture HTTP/HTTPS from ElectronJS apps
* 1-click setup
* No source code changes. It just works :white\_check\_mark:

## 3. How to use

1. Start the Proxyman app: Make sure you've already installed and trusted the Proxyman Certificate on your Mac. If not, follow the guide in Certificate Menu -> Install Certificate on this Mac -> Automatic Tab
2. Open the Setup Menu -> Automatic Setup
3. Click the "Select ElectronJS App…" button and select the app you'd like to capture (Make sure to quit your Electron app first)
4. Done :white\_check\_mark:
