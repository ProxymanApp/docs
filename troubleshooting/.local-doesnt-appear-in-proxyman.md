# \*.local requests do not appear on Proxyman

## 1. Problem

* All requests appear in Proxyman, except some local requests (`*.local` or `localhost`).

{% hint style="info" %}
For `.local` servers on your local network, try [Network Extension](../advanced-features/network-extension.md) to capture HTTP/HTTPS traffic from Mac apps that bypass the system proxy. For `localhost` requests, use the setup guide below.

Network Extension is BETA and requires Proxyman PRO on macOS 26 or later.
{% endhint %}

## 2. Solution

* If it's a `localhost` request, read the following page:

{% content-ref url="couldnt-see-any-request-from-localhost-server.md" %}
[couldnt-see-any-request-from-localhost-server.md](couldnt-see-any-request-from-localhost-server.md)
{% endcontent-ref %}

* If it's a `*.local` request:

Open **System Settings** -> **Network** -> **Wi-Fi** -> **Details…** -> **Proxies**, then remove `*.local` from "Bypass proxy settings for these hosts & domains".

If you installed the Proxy Helper Tool, Proxyman uses its own [Bypass Proxy List](../basic-features/bypass-proxy-list.md) while it runs. Open **Tools** -> **Proxy Settings** -> **Bypass Proxy Settings…** in Proxyman and make sure `*.local` is not in the list.
